# ARC Claude Code Starter Pack

1. Extract this archive into a new (or existing) `arc` project directory.
2. Open a terminal at that project root, and run `claude`.
3. Paste the contents of `prompts/START_WITH_CLAUDE_CODE.md` **starting at** `You are the principal engineer...` (do not include the header above the separator).
4. Claude Code must read `docs/ARC_Research_and_Roadmap_2026.md` and implement R0/R1 in stages.
5. Do not consider R1 finished until its acceptance gates pass.

Project name `arc` is provisional; check existing binaries and legal naming before public release.
