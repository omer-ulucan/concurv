Fourth pre-release of **concurv**, a local-first version control system in
Rust built so that people and AI agents working in parallel, on one machine
or several, never silently lose acknowledged work. New since alpha.3:
**deleting and renaming branches**, **removing workspaces**, **tags at the
relay**, and a **side-by-side comparison with Git**.

> **Alpha.** The CLI/JSON contract may still change before 0.1.0. No new
> repository format: alpha.3 repositories open unchanged. A relay must run
> alpha.4 to keep tags; older relays simply have none.
>
> **No license has been chosen yet.** Until the owner adds one, the code and
> binaries are published for evaluation only, with no license granted.

## New

- **`concurv branch delete <name>`** removes a branch name; its snapshots
  stay and the output prints the head. Refused while a workspace tracks
  the branch, for protected branches (exit 44), and when no other branch,
  tag, workspace or remote-tracking reference holds its work (exit 42: tag
  or merge it first).
- **`concurv branch rename <old> <new>`**: the workspaces tracking the
  branch follow in the same operation; no files change. Protected branches
  cannot be renamed.
- A branch you deleted or renamed is **not brought back by `fetch`**; only
  `remote/<relay>/<branch>` follows the relay, and `branch create <b> --at
  remote/origin/<b>` restores it.
- **`concurv workspace remove <name>`** unregisters a finished workspace.
  Its directory and files stay; removal is refused with unsaved changes, a
  pending merge or work no other reference holds.
- **Tags at the relay**: `concurv push --tags` creates your tags there
  (create-only, for published snapshots, all or nothing); `fetch` and
  `clone` bring the relay's tags and never move a local tag.
- **Comparison harness** (`bench/scenarios/`): seven scenarios for
  concurv, Git and Jujutsu. Measured on Windows and Linux: concurv passes
  all seven. Git overwrote an unsaved edit when restoring an older version
  (both systems), and on Windows it missed a same-size rewrite whose
  modification time was put back. concurv's `status` is slower than Git's at
  10,000 files (Windows 804 vs 153 ms, Linux 67 vs 9 ms). The Jujutsu scripts
  have not run yet. Details: `docs/benchmarks/comparison-plan.md`.

## Everything from alpha.3

Protected branches with recorded checks, agent intents and overlap
warnings, tags and Git round trips, configuration and completions, sync
between machines through a relay you run, named branches, private
workspaces, line-level merge, recorded conflicts, `undo`, safe `restore`,
`--json` everywhere. See `CHANGELOG.md`.

## Not yet

A license (the owner's decision), macOS release builds, deleting branches
or tags at a relay, explicit `track`/`untrack`, sandboxed checks,
signatures, rename detection, garbage collection, several repositories
per relay, symlinks on Windows. Roadmap: `docs/ROADMAP_REVISED.md`; status
and evidence: `docs/ROADMAP_STATUS.md`.

## Install

Download the archive for your platform below, check it against
`SHA256SUMS`, and put `concurv` and `concurvd` on your `PATH`. Builds:
**Linux x86_64** (static, musl: runs on any distribution) and **Windows
x86_64**. The binaries are not code-signed.

This release was built and tested on the project's local CI (Windows 11
and Linux under WSL). **There is no macOS build**: on a Mac, build from
source with Rust 1.89+:
`cargo install --git https://github.com/omer-ulucan/concurv --tag v0.1.0-alpha.4 concurv-cli`
(installs both binaries). macOS was last tested at R2.5 (hosted CI,
2026-11-02); the code added since has not run on macOS.

Full guide: `docs/user-guide.md`. Changes: `CHANGELOG.md`.
