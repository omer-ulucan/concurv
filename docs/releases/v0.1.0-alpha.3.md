Third pre-release of **concurv**, a local-first version control system in
Rust built so that people and AI agents working in parallel, on one machine
or several, never silently lose acknowledged work. New since alpha.2:
**protected branches** (only snapshots that passed their checks get
published), **coordination between agents** (intents and overlap
warnings), **tags**, and a **Git bridge that works both ways repeatedly**.

> **Alpha.** The CLI/JSON contract may still change before 0.1.0. This
> release adds repository formats 3 (the first `concurv check`) and 4 (the
> first tag); alpha.2 cannot open a repository once it has been upgraded.
> Keep your Git history as the source of truth for anything important.
>
> **No license has been chosen yet.** Until the owner adds one, the code and
> binaries are published for evaluation only, with no license granted.

## New: protected branches (R4, RFC 0005)

- A `concurv-policy.json` in a branch's current head can `protect` it.
  Publishing (and pushing to a relay) then needs a recorded **passing
  check of exactly the snapshot being published**, under exactly that
  policy version.
- **`concurv check [--branch B] [--trust]`** runs the policy's commands on a
  fresh checkout of the saved snapshot (never your working files), with a
  cleared environment and timeouts, and records an attestation.
  `publish --check` checks first. Policies run only after you approve that
  version on your device; they run **without a sandbox**, and the policy
  must say so (`"sandbox": "none"`).
- Two changes that pass separately but fail together cannot be published.
  A change cannot weaken the policy that judges it. The relay enforces the
  same rules.

## New: coordination between agents (R5, RFC 0006)

- **`concurv intent declare|list|release`**: say which paths or functions
  you are about to change, for 1 minute to 7 days. Intents travel through
  the relay and are advisory: they warn, they never lock.
- **`concurv overlaps`** warns about files changed elsewhere, edits that
  would conflict, matching intents, and functions you call whose signature
  changed upstream (also on another machine, after `fetch`). Measured on a
  seeded corpus: conflict warnings missed no real conflict (5.4% false
  alarms); signature-change warnings raised no false alarms and missed
  36.5% of real cases, all calls through a function table.
- **`concurv events`**: the operation log as versioned JSON lines.

## New: tags, configuration, Git round trips (R6, ADR 0008)

- **`concurv tag create|list|delete`**: names that never move; `--at`
  accepts branches, tags and snapshot ids (also in `branch create`).
- **`git export --tags`** and **`git import --tags`**.
- **`git import` into existing history**: only new Git commits are
  imported, on top of what concurv already has; Git → concurv → Git keeps
  the Git commit ids. A diverged branch is refused; `--into <branch>`
  imports beside it so you can `concurv merge` it.
- **`concurv config`** (`author`, `remote`; per repository or `--global`)
  and **`concurv completions <shell>`**.
- `CONTRIBUTING.md`, `SECURITY.md` (report vulnerabilities privately through
  GitHub), a code of conduct, issue and pull request templates.

## Everything from alpha.2

Sync between machines through a relay you run (`concurvd`, pinned TLS,
devices and scopes, `clone`/`fetch`/`push`), named branches, private
workspaces, compare-and-swap `publish`, line-level merge, recorded
conflicts, `undo`, safe `restore`, Git-compatible ignores, `--json`
everywhere. See `CHANGELOG.md`.

## Not yet

A license (the owner's decision), macOS release builds, tags at the relay,
branch delete/rename, sandboxed checks, signatures, rename detection,
garbage collection, several repositories per relay, symlinks on Windows.
Roadmap: `docs/ROADMAP_REVISED.md`; status and evidence:
`docs/ROADMAP_STATUS.md`.

## Install

Download the archive for your platform below, check it against
`SHA256SUMS`, and put `concurv` and `concurvd` on your `PATH`. Builds:
**Linux x86_64** (static, musl: runs on any distribution) and **Windows
x86_64**. The binaries are not code-signed.

This release was built and tested on the project's local CI (Windows 11
and Linux under WSL). **There is no macOS build**: on a Mac, build from
source with Rust 1.89+:
`cargo install --git https://github.com/omer-ulucan/concurv --tag v0.1.0-alpha.3 concurv-cli`
(installs both binaries). macOS was last tested at R2.5 (hosted CI,
2026-11-02); the code added since has not run on macOS.

Full guide: `docs/user-guide.md`. Changes: `CHANGELOG.md`.
