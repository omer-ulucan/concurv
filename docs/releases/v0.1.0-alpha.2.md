Second pre-release of **concurv**, a local-first version control system in
Rust built so that people and AI agents working in parallel, on one machine
or several, never silently lose acknowledged work. New since alpha.1:
**named branches** and **sync between machines** through a relay you run
yourself.

> **Alpha.** The CLI/JSON contract may still change before 0.1.0. Adding a
> remote upgrades a repository to **format 2**, which alpha.1 cannot open.
> Keep your Git history as the source of truth for anything important.
>
> **No license has been chosen yet.** Until the owner adds one, the code and
> binaries are published for evaluation only, with no license granted.

## New: sync between machines (R3, RFC 0003)

- **`concurvd`**, the relay: one directory holds a repository's objects and
  the authoritative head of each published branch. `concurvd init`,
  `device add|list|revoke`, `serve`. Clients pin the relay's certificate
  fingerprint (TLS 1.3); every device has its own token with scopes
  (`read`, `write`, `publish:<branch>`).
- **`concurv clone | fetch | push`** and **`remote add|list|remove`**.
  `fetch` records the relay's heads as remote-tracking references
  (`remote/origin/main`) and fast-forwards local branches that are behind.
  It never touches working files. `push` is a compare-and-swap at the
  relay, fast-forward only.
- **Nothing is published or overwritten implicitly.** If two machines
  published offline, the second push is refused (exit 42). It runs `concurv
  merge remote/origin/main`, publishes, and pushes again. A race between
  two pushes has one winner (exit 41 for the other). A push retried after a
  lost reply is never applied twice.
- **Nothing a peer sends is trusted.** Every object is verified, and a
  history must be complete before anything refers to it. A relay whose
  head went backwards is reported and not followed.
- Tested with two machines reconnecting in both orders, racing pushes,
  disconnects at every byte of a transfer, malformed traffic, a wrong
  certificate, a lying relay, injected I/O failures at every write step,
  and real relay and client processes killed mid-push.

## New: branches (R2.5, ADR 0007)

`branch create [--at | --switch]`, `branch list`, transactional `branch
switch` (refuses to lose work, rolls back on failure, resumable after a
crash), `merge <branch>`, `workspace add --branch`, `git export --from`.
Branch names follow Git's rules, checked against `git check-ref-format`,
plus a portability policy.

## Everything from alpha.1

Private workspaces, compare-and-swap `publish`, `update` with line-level
merge of non-overlapping edits, recorded conflicts, `undo`, safe `restore`,
Git-compatible ignores, the stat cache, Git export/import, `--json`
everywhere. See `CHANGELOG.md`.

## Not yet

Verified integration gates (R4), agent coordination (R5), branch
delete/rename, tags, rename detection, garbage collection, several
repositories per relay, symlinks on Windows. Roadmap:
`docs/ROADMAP_REVISED.md`; status and evidence: `docs/ROADMAP_STATUS.md`.

## Install

Download the archive for your platform below, check it against
`SHA256SUMS`, and put `concurv` and `concurvd` on your `PATH`. Builds:
**Linux x86_64** (static, musl: runs on any distribution) and **Windows
x86_64**. The binaries are not code-signed.

This release was built and tested on the project's local CI (Windows 11
and Linux under WSL; hosted CI was unavailable). **There is no macOS build
this time**: on a Mac, build from source with Rust 1.89+:
`cargo install --git https://github.com/omer-ulucan/concurv --tag v0.1.0-alpha.2 concurv-cli`
(installs both binaries). macOS was last tested at R2.5 (hosted CI,
2026-11-02); the sync code of this release has not run on macOS yet.

Full guide: `docs/user-guide.md` (syncing: §8a). Changes: `CHANGELOG.md`.
