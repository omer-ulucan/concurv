First public pre-release of **concurv**: a local-first version control system
in Rust, built so that several people or AI agents working in parallel never
silently lose acknowledged work.

> **Alpha.** The on-disk format (version 1) and the CLI/JSON contract may
> still change before 0.1.0, and repositories made by this build may then
> need re-importing (for example through `concurv git export` / `git import`).
> Keep your Git history as the source of truth for anything important.
>
> **No license has been chosen yet.** Until the owner adds one, the code and
> binaries are published for evaluation only, with no license granted.

## What works

Single machine, with any number of private workspaces sharing one `main`:

- `init`, `status`, `diff`, `save`, `log`, `restore` (never overwrites unsaved
  work without `--force` plus a backup snapshot), `verify [--full]`,
  `op log`, `undo`.
- Workspaces: `workspace add/list`, `publish` (compare-and-swap; exit 42 if
  `main` moved), `update` (fast-forward or three-way merge).
- Merging: file level, plus **line-level merging** of text files whose edits
  don't overlap or touch (new). Real conflicts are refused, or with
  `--allow-conflicts` recorded and resolved in the working copy.
- **Git-compatible ignores** (new): `.gitignore` at any depth, negation,
  anchors, `**`, plus a local `.concurv/exclude`; `concurv check-ignore`.
  Tracked files stay tracked. Ignored files are never overwritten, even with
  `--force`, and `.git/` is never versioned or written into.
- **Faster `status` and `save`** (new). On Linux and macOS a stat cache lets
  `status`/`diff` skip unchanged files. It is never used for a snapshot and
  passes a false-clean test suite (ADR 0005). `save` no longer rewrites
  objects it already has: a no-op save of 10k files went from 46 s to 1.7 s
  on the reference Windows machine. See `bench/RESULTS.md`.
- Git bridge: `git export` / `git import` of a branch with full history.
- `--json` on every command, with stable error and exit codes (`docs/cli.md`).

Durability: every acknowledged `save`/`publish` is fsynced and committed by
an atomic replacement of one pointer. The project's own fault-injection,
killed-process and 10-concurrent-writer tests run on Linux, macOS and
Windows in CI.

## Install

Download the archive for your platform below, check it against
`SHA256SUMS`, and put `concurv` (`concurv.exe` on Windows) on your `PATH`.
Builds: Linux x86_64 (glibc), macOS Apple Silicon and Intel, Windows x86_64.
The binaries are not code-signed. On macOS, run
`xattr -d com.apple.quarantine concurv` once if Gatekeeper blocks it.

Or build from source with Rust 1.89+:
`cargo install --git https://github.com/omer-ulucan/concurv --tag v0.1.0-alpha.1 concurv-cli`.

Full guide: `docs/user-guide.md`. Changes: `CHANGELOG.md`.
