**concurv 0.1.0** is the first stable release of concurv, a local-first
version control system in Rust built so that people and AI agents working
in parallel, on one machine or several, never silently lose acknowledged
work.

## What 0.1.0 promises

`docs/compatibility.md` in full; in short:

- **Your data:** every later release opens repositories of formats 1 to 4
  exactly as this one does. A feature that needs a new format upgrades a
  repository in place, only when you first use it, and never rewrites
  objects. Older builds refuse newer formats instead of misreading them.
- **Your scripts:** `--json` output (version 1) only gains fields; exit
  codes and `CONCURV_*` error codes keep their meaning.
- **Versions:** Semantic Versioning. Patch releases only fix bugs; changes
  that can break a script come in minor releases and are marked in the
  changelog.
- **Platforms:** Windows x86_64 and Linux x86_64 are supported: every
  release passes the full test gate on both, and binaries are published.
  macOS builds from source but has not been tested since 2026-11-02.

## What it does

- **Private workspaces** for each person or agent, sharing named branches;
  `save` is private and durable, `publish` moves a branch by
  compare-and-swap, `update`/`merge` integrate with line-level merging and
  recorded conflicts; `undo` reverses only your own workspace's steps.
- **Never loses acknowledged work:** fsync'd saves, verified objects,
  `restore` refuses to overwrite unsaved edits without a backup, branch and
  workspace removal refuse while work would be left on no reference.
  Tested with injected I/O failures at every write step, killed processes
  and concurrent writers.
- **Sync between machines** through a relay you run (`concurvd`): pinned
  TLS, per-device tokens and scopes, fetch/push that never publish or
  overwrite implicitly; tags travel through the relay.
- **Protected branches:** publish only snapshots whose recorded checks
  passed, under exactly the policy in force.
- **Agent coordination:** advisory intents, warnings about overlapping or
  dependent work, the operation log as JSON events.
- **Git:** export and import both ways, repeatedly, with tags.
- Tags, branch delete/rename, configuration files, shell completions,
  `--json` everywhere.

Compared side by side with Git on seven scenarios on Windows and Linux
(`bench/results/`, `docs/benchmarks/comparison-plan.md`).

## Upgrading from the alphas

Nothing to do: repositories and relays of every 0.1.0 alpha open
unchanged. Running a relay in production: `docs/operations.md`.

## Install

Download the archive for your platform below, check it against
`SHA256SUMS`, and put `concurv` and `concurvd` on your `PATH`. Builds:
**Linux x86_64** (static, musl: runs on any distribution) and **Windows
x86_64**. Each archive contains `LICENSE-MIT`, `LICENSE-APACHE` and
`THIRD-PARTY-LICENSES.md`. The binaries are not code-signed.

On macOS (or anywhere), build from source with Rust 1.89+:
`cargo install --git https://github.com/omer-ulucan/concurv --tag v0.1.0 concurv-cli`
(installs both binaries).

Full guide: `docs/user-guide.md`. Changes: `CHANGELOG.md`.
